### 🎓 [Al-Tanweer](https://altanweer.net)

**Production educational platform used by real teachers.**

Al-Tanweer provides teachers with controlled access to educational materials based on subscriptions and permissions, with a complete administration system for managing users, packages, devices, content, and access.

**Engineering highlights:**
- Role-, subscription-, and permission-based access control
- Multi-device authentication and session management
- Administrative dashboard for users, subscriptions, content, packages, and registered devices
- Production deployment on AWS ECS Fargate
- PostgreSQL database hosted on Amazon RDS
- S3 and CloudFront for content storage and delivery
- Automated tests and build checks with GitHub Actions

**Tech:** Next.js • React • TypeScript • PostgreSQL • Prisma • AWS ECS Fargate • RDS • S3 • CloudFront

[🌐 Live Platform](https://altanweer.net)
